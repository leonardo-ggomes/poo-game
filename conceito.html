⚔️ ARENA — Veja Herança em Ação!

Todos os heróis herdam de Personagem. Mas cada um tem habilidades únicas — isso é Herança!

// Classe PAI (superclasse) open class Personagem(val nome: String, val hp: Int) { open fun atacar(): Int = 10 // ataque base } // Classes FILHAS (subclasses) — herdam de Personagem class Guerreiro(nome: String) : Personagem(nome, 100) { override fun atacar() = 30 // sobrescrita! } class Mago(nome: String) : Personagem(nome, 60) { override fun atacar() = 50 // mais dano, menos HP }

🔮 POLIMORFISMO — Um Feitiço, Muitos Efeitos!

Polimorfismo = mesma função, comportamentos diferentes! Chame atacar() em qualquer herói e cada um reage de seu jeito.

// Uma lista com tipos DIFERENTES, mas todos são Personagem val grupo: List<Personagem> = listOf( Guerreiro("Thorin"), Mago("Merlin"), Arqueiro("Legolas") ) // Mesmo código, resultados diferentes — POLIMORFISMO! for (heroi in grupo) { println("${heroi.nome} ataca com ${heroi.atacar()} de dano!") }

🧠 ENCAPSULAMENTO — Proteja seus Segredos!

Em Kotlin, use private para esconder atributos e get/set para controlá-los. Como uma armadura protege o herói!

class Mago(nome: String) { private var _mana = 100 // privado — ninguém acessa diretamente! var mana: Int // propriedade pública com proteção get() = _mana set(valor) { if (valor >= 0) _mana = valor // validação! } }
